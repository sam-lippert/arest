# An abbreviation before a number is inside its sentence

### `... compliance with Art. 28 to Controller. *` was split at "Art." and the
### tail "28 to Controller." read as a fact type of its own: eu-law carried
### 28ToController and sixteen more numeric heads, every one a marked derived
### fact type nothing could derive (2026-09-09). A short capitalized word, a
### period and a number is an abbreviation; the sentence runs on through it,
### so the reading below is one binary and the rule over it builds.

Processor(.name) is an entity type.
Controller(.name) is an entity type.

Processor makes available information necessary to demonstrate compliance with Art. 28 to Controller.
Processor is compliant with Art. 28. *

* Processor is compliant with Art. 28 iff Processor makes available information necessary to demonstrate compliance with Art. 28 to some Controller.
