# Six legs on a subtype subject: which one breaks

Covenant(.terms) is an entity type.
Real Covenant is a subtype of Covenant.
Writing(.id) is an entity type.
Land(.parcel) is an entity type.
Successor(.name) is an entity type.
Original Party(.name) is an entity type.
Notice(.id) is an entity type.

Covenant is in Writing.
Original Parties intended Covenant to run.
Covenant Touches And Concerns Land.
Covenant was made in Horizontal Privity between Original Parties.
Covenant runs to Successor in Vertical Privity with Original Party.
Successor has Notice of Covenant.
Real Covenant runs with Land at law. *

* Real Covenant runs with Land at law iff Real Covenant is in Writing and Original Parties intended Real Covenant to run and Real Covenant Touches And Concerns Land and Real Covenant was made in Horizontal Privity between Original Parties and Real Covenant runs to some Successor in Vertical Privity with some Original Party and that Successor has Notice of Real Covenant.
