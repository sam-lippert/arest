# The us-law shape exactly: Intent a value, Boundaries plain text

Defendant(.name) is an entity type.
Plaintiff(.name) is an entity type.
Intent is a value type.
Confinement(.description) is an entity type.

Defendant acts with Intent.
Plaintiff is confined within Boundaries fixed by Defendant.
Plaintiff is aware of Confinement or harmed by it.
Defendant is liable for false imprisonment. *

* Defendant is liable for false imprisonment iff Defendant acts with Intent and Plaintiff is confined within Boundaries fixed by Defendant and Plaintiff is aware of Confinement or harmed by it.
