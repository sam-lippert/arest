# Several negated legs on one unary head, with and without a positive leg

Invention(.identifier) is an entity type.
Printed Publication(.identifier) is an entity type.
Patent(.patent_number) is an entity type.

Invention was patented before filing.
Invention was described in Printed Publication before filing.
Invention was in public use before filing.
Invention is useful.
Invention claims abstract idea.
Invention claims law of nature.
Invention is novel. *
Invention is eligible subject matter. *

* Invention is novel iff it is not true that Invention was patented before filing and it is not true that Invention was described in Printed Publication before filing and it is not true that Invention was in public use before filing.
* Invention is eligible subject matter iff Invention is useful and it is not true that that Invention claims abstract idea and it is not true that that Invention claims law of nature.
