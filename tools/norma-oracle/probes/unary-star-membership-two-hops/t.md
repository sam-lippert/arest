# A membership leg two hops down the subtype chain beside a unary

Interest(.identifier) is an entity type.
Remainder(.identifier) is an entity type.
Contingent Remainder(.identifier) is an entity type.
Remainder is a subtype of Interest.
Contingent Remainder is a subtype of Remainder.

Interest might not vest in time.
Interest violates the rule. *

* Interest violates the rule iff Interest is a Contingent Remainder and that Interest might not vest in time.
